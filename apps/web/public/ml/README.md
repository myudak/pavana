# Historical research export

`research.json` is generated by `ml/notebooks/00_cloud_setup.ipynb` from the evaluated
`cams-t6h-retro-kaggle-explain-v1` run. It is real research output, not the synthetic app fixture.

It contains 168 historical cases, 44 ordered features, Tree SHAP contributions, global importance
over 1,000 seeded holdout samples, and A–E metrics on identical test rows. The target is the CAMS
model field, not station observations. All serving/observation-validation flags remain false.

The model checksum, code/data revisions, SHAP version, and timestamps are embedded in the export.
The web client parses it through `ResearchBundleSchema`, including the SHAP additivity check.
Regenerate from the notebook, verify the artifact, and copy `research.json` here; do not edit values
or flags manually. This asset is used only by `/lab-ml`, independently of the selected live location.
