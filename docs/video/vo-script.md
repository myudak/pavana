# Naskah voice-over: Pavana v2 (2:00)

Rekam **satu file per baris** dan simpan di `apps/video/public/vo/` dengan nama persis seperti
kolom "File" (`.wav` atau `.mp3`). Setelah itu jalankan render ulang. Panjang tiap adegan otomatis
menyesuaikan durasi rekaman (ditambah 0,6 detik jeda). Subtitle di video memakai teks yang sama
persis dengan naskah ini (`apps/video/src/v2/script.ts`), jadi kalau kalimatnya diubah saat
merekam, ubah juga di file itu.

Tips merekam:

- Tempo santai sekitar 2,2 kata per detik, nada tenang dan jelas, bukan nada iklan.
- Beri jeda kecil di tanda koma, dan jeda lebih panjang di titik.
- Ruangan senyap, mikrofon 15–20 cm dari mulut, tanpa musik latar (musik ditambahkan nanti).
