\section*{Data and code availability}
\addcontentsline{toc}{section}{Data and code availability}

All inputs are public and need no keys: METAR reports from the Iowa Environmental Mesonet
\citep{iem} and VIIRS S-NPP yearly active-fire archives from NASA FIRMS \citep{firms}. The data
snapshot used here (built 16 October 2026) is fixed by file checksums. Feature construction, model
training, the statistical analysis, every figure and every number quoted in the text are
generated by scripts in the accompanying repository; numbers in the manuscript are inserted from
the result tables, not typed. The exposure kernel and wind conversions are shared with the
open-source Pavana application, whose TypeScript and Python implementations are tested against
common vectors. [Repository URL to be added at submission.]
