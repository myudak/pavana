# Fixtures

Everything in this folder is **synthetic** unless a file says otherwise with a verifiable,
timestamped source. Fixtures power demo mode (`PAVANA_MODE=demo`), tests, and notebooks, so
the app runs with **no API keys**.

| File                         | What                                                                                                                     | Provenance                                                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ |
| `scenario-kubu-raya.json`    | 24 h smoke-episode scenario near Sungai Raya, Kubu Raya (Kalbar): hourly PM2.5, wind, weather + 14 VIIRS-shaped hotspots | **Synthetic**, generated by `scripts/generate-kubu-raya.mjs` (seeded, deterministic)       |
| `regional-kalimantan-hotspots.json` | ~1346 synthetic hotspot detections across Kalimantan (4 connected belts of overlapping anisotropic sub-clusters, 10 small centers, background) for the regional density view | **Synthetic**, generated by `scripts/generate-kalimantan.mjs` (seeded, deterministic); 75 km keep-out around Sungai Raya so the Kubu Raya scenario stays authoritative there |
| `test-vectors/geo-wind.json` | Hand-derivable math cases (haversine, wind from→to, upwind score)                                                        | Shared by Vitest (`packages/shared`) and pytest (`ml/tests`) to keep TS and Python in sync |

## Rules

- Every datum carries `provenance` with `isDemo: true` and `kind: "fixture"`.
- The UI must show **"Mode Demo · Data ilustratif"** whenever fixture data is displayed.
- Never add fake _official_ warnings, evacuation notices, or real-looking incident reports.
- If you add a fixture derived from a real historical episode, add its source URL, download
  date, license, and any transformations here.
- Regenerate: `node fixtures/scripts/generate-kubu-raya.mjs` (commit the output).

## Scenario shape

```jsonc
{
  "meta": { "id", "title", "isDemo": true, "synthetic": true, "referenceTime", ... },
  "location": { "id", "name", "admin1", "admin2", "country", "lat", "lon", "timezone" },
  "hours": [ { "validAt", "airQuality": AirQualityPoint, "weather": WeatherPoint } ],   // hours[0] = "now"
  "hotspots": [ Hotspot ]
}
```

Types are defined in `packages/shared/src/schemas` — the API validates the fixture against
them at load time.
